# Pennywise – Personal Expense Tracker

**Pennywise** is a personal finance management web application designed to help users track their daily income and expenses, monitor their spending habits, and manage their remaining balance through a simple and user-friendly dashboard.

## Features

- **User Authentication:** Login and registration functionality.
- **Financial Dashboard:** Displays total income, total expenses, and remaining balance.
- **Add Transactions:** Add daily income and expense transactions.
- **Transaction Categories:** Categorize transactions, such as Salary and Shopping.
- **Date Management:** Record transactions with their respective dates.
- **Transaction History:** View previously added transactions in an organized table.
- **Delete Transactions:** Remove unwanted transactions.
- **Currency Support:** Displays financial amounts in Indian Rupees (₹).

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Pennywise-Expense-Tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Pennywise-Expense-Tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables, if applicable.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open your browser and visit:

   ```text
   http://localhost:3000
   ```
